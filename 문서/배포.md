## 설정 값
| 이름 | 어디에 넣나 | 뜻 |
|---|---|---|
| `TURSO_DATABASE_URL` | Vercel 환경 변수 · GitHub 저장소 Secrets | `libsql://...turso.io` |
| `TURSO_AUTH_TOKEN` | Vercel 환경 변수 · GitHub 저장소 Secrets | DB 열쇠 (비밀 · 저장소에 넣지 않기) |
| `REVALIDATE_SECRET` | Vercel 환경 변수 · GitHub Secrets | 수집 끝나면 사이트 저장(5분 캐시)을 바로 지우는 신호용 비밀값 |
| `SITE_URL` | GitHub 저장소 Variables | 사이트 주소(신호 보낼 곳) |
| `ADMIN_EMAILS` | Vercel 환경 변수 | 관리자 이메일(쉼표로 여러 개) · 「수익 계산법」 페이지는 관리자만 · 로컬은 `.env.local` |
